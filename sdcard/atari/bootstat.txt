# This file tells stdio glue code to fast fail, fast stat certain files
# that are accessed at boot time in order to speed up the boot process.
#
# The Atari 800 build compiles the Altirra OS/BASIC ROMs in, so there are
# no required external ROMs and this list stays empty: an empty list means
# no faked stat/open results, so the ROM probes in atari800_config.cpp see
# the real SD card. Optional ROMs from ROMS.txt need no entries here.
